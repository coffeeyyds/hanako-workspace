# 👋 欢迎来到你的 Obsidian 知识库

这是 Hanako 帮你创建的 Obsidian Vault。

## 为什么用 Obsidian？

- **本地优先**：所有笔记都是纯 Markdown 文件，不依赖任何云服务
- **双向链接**：用 `[[笔记名]]` 链接任意笔记，构建知识网络
- **和 Hanako 配合**：Hanako 可以直接读写这个文件夹里的 Markdown 文件，帮你整理、生成、分析笔记

## 快速上手

1. 按 `Ctrl+N` 创建新笔记
2. 用 `[[` 创建链接到其他笔记
3. 按 `Ctrl+P` 打开命令面板
4. 左侧可以看到知识图谱（关系图）

## Hanako 能帮你做什么

- 把对话中的重要信息自动整理成笔记
- 批量分析和归类你的笔记
- 生成日报/周报存入 Obsidian
