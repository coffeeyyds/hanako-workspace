## 全国手帐市场开店分析报告

**报告日期**：2026年5月  
**报告类型**：行业调研与实体店可行性分析  

---

### 一、市场规模概述

手帐（てちょう/手帳）起源于日本，21世纪10年代起在国内年轻人中迅速流行，现已发展为涵盖纸质手账本、胶带、贴纸、印章、钢笔/彩墨、书衣、手帐工具等全品类的文创细分市场。手帐在中国属于**文具/文创消费品**大类的子赛道，其核心消费群体为15-35岁女性，约占总消费人数的80%以上。

根据行业综合估算：

| 指标 | 数据 |
|------|------|
| 中国文具市场规模 | 约1,500-1,800亿元（2024年） |
| 文创文具细分市场 | 约300-400亿元 |
| 手帐及周边市场 | 约50-80亿元 |
| 年增长率（CAGR 2024-2028） | 约12-18% |
| 核心用户群体规模 | 约2,000-3,000万活跃用户 |

**增长驱动因素**：
- 小红书、B站等平台推动手帐文化传播（#手帐#话题超百亿次浏览）
- 国产品牌崛起（kinbor、本子事多、九口山、陌墨等）
- "悦己消费"与"慢生活"趋势强化
- 手帐集市/手帐展（每年全国超100场）激活线下消费场景

### 五、开店策略建议

#### 5.1 首选城市推荐

**第一梯队**：成都、重庆  
- 理由：手帐文化氛围浓厚、租金成本可控、竞争尚未饱和、年轻人聚集
- 成都建议选址：宽窄巷子周边、太古里文创区、川大/川美附近
- 重庆建议选址：鹅岭二厂文创园、川美虎溪校区附近

**第二梯队**：杭州、广州  
- 理由：产业生态完善、消费力强，但租金和竞争高于第一梯队
- 杭州建议选址：运河文化创意区、下沙大学城
- 广州建议选址：东山口文艺区、大学城

**避坑提示**：上海/北京虽然市场大，但租金成本和竞争激烈度极高，不建议作为首店选址，可待品牌成熟后以旗舰店形式进入。

#### 5.2 差异化经营策略

1. **"手帐+咖啡"复合业态**：40㎡空间拿10㎡做饮品区，提升客单价和驻留时间
2. **手帐工作坊**：每周举办2-3场workshop（胶带拼贴、brush lettering、子弹笔记入门），收取68-128元/人，毛利率70%+
3. **社群运营**：建立微信群/小红书社群，每月会员日专属折扣，绑定复购
4. **线上联动**：同步运营小红书账号+微店/淘宝，线下体验+线上复购
5. **买手选品**：差异化选品，不做大而全，做"有审美的精选买手店"

#### 5.3 风险提示

- 手帐属于非刚需消费品，受宏观经济和消费信心影响明显
- 国产手帐品牌价格内卷，日系品牌进口成本高且受汇率波动影响
- 实体店流量依赖选址，线上流量依赖内容运营能力
- 行业季节性明显（开学季+节假日高峰，夏季偏淡）

---

### 六、总结

全国手帐市场处于**快速增长期**，市场规模约50-80亿元，年增速12-18%。成都和重庆因为"手帐文化氛围浓厚+租金可控+竞争不饱和"三大优势，是当前最适合手帐实体店创业者入场的城市。

一家40㎡的手帐文具集合店，启动投入约7-18万元（因城市而异），在成都/重庆等城市有望8-14个月实现回本。核心成功要素在于：选址（大学城/文创区）、选品（差异化买手路线）、社群（线上+线下联动）和复合业态（零售+体验）。
