## 1. 估值方法论

### 1.1 绝对估值法：DCF（现金流贴现）

**原理**
企业价值 = 未来所有能分配给股东的自由现金流，按适当贴现率折现到今天。

```
企业价值 = Σ (第t年自由现金流 / (1+r)^t) + 终值/(1+r)^n
```

**三个核心变量**
- **自由现金流预测**：最难的部分，微小变化导致巨大结果差异
- **贴现率 r**（WACC）：加权平均资本成本，反映风险和机会成本
- **终值**：通常占 DCF 结果的 60-80%，假设永续增长率 g

**怎么用**
适合盈利稳定、现金流可预测的公司（消费、公用事业、基础设施）。不适合初创公司、强周期公司。

**核心陷阱**
- "垃圾进垃圾出"：假设稍变，结果天差地别
- 终值假设的杠杆效应：永续增长率从 2% 改到 3%，价值可能翻倍
- 过分追求精确反而远离正确；DCF 的价值在于过程（逼你思考企业到底怎么创造价值），
  不在结果那个精确数字

**实战心法**
做 DCF 不是为了算出一个目标价，而是逼自己回答几个问题：
这家公司 5 年后能赚多少钱？10 年后还能以什么速度增长？
维持这个增长需要多少资本投入？如果这些问题回答不了，DCF 再精美也没用。

### 1.2 相对估值法：倍数法

**常用倍数**
| 倍数 | 适用场景 | 注意事项 |
|------|---------|---------|
| PE（市盈率） | 盈利稳定的成熟企业 | 不考虑负债水平和资本结构 |
| PB（市净率） | 金融、重资产行业 | 无形资产占比大的公司不适用 |
| PS（市销率） | 高成长、尚未盈利的公司 | 不考虑盈利能力差异 |
| EV/EBITDA | 跨资本结构比较时 | 最适合比较不同负债水平的同行 |
| PEG | 成长型公司 | 增长率不可靠则 PEG 无意义 |
| EV/FCF | 综合考察现金产出能力 | 资本支出波动大时不稳定 |

**倍数法使用的核心原则**
- **可比公司必须真的可比**：同一行业、相似规模、相似增长阶段
- **不要只看单一倍数**：PE + PB + PS 三轮交叉验证
- **理解倍数背后的驱动力**：高 PE 可能是因为高成长，也可能是因为泡沫
- **关注倍数的分布**：看行业中位数而非均值，看历史分位数

**A 股特有问题**
- 行业分类粗糙，很多公司主业和分类标签不匹配
- 小票的估值体系和大票完全不一样，只看 PE 会被误导
- 壳价值（未被计入但客观存在的隐形资产）影响小盘股定价

### 1.3 其他估值方法

**净资产价值法（NAV）**：适用于资产价值容易量化的公司（房地产、矿业、持有大量金融资产的企业）

**股息贴现模型（DDM）**：适用于高分红、稳定派息的公司（银行、公用事业）

**清算价值法**：公司如果立刻破产清算，能收回多少？适用于极度困境反转判断

**分部加总法（SOTP）**：适用于多元化业务集团，对每个业务分部独立估值再加总（如复星、腾讯）

## 2. 宏观分析框架

### 2.1 三驾马车框架

GDP = 消费 + 投资 + 净出口

这是最基础的宏观分解，但会掩盖结构性问题：
- 投资中多少是房地产？多少是制造业升级？多少是无效基建？
- 消费中多少是必需消费，多少是可选消费？疫情后是「报复性消费」还是「消费降级」？
- 净出口受益于人民币贬值还是真实竞争力提升？

### 2.2 货币信用框架

**核心变量**
- **量**：M2 增速、社融增速、信贷脉冲
- **价**：政策利率（7 天逆回购 / MLF / LPR）、市场利率（DR007、10 年国债收益率）
- **结构**：谁在借钱？（政府 vs 企业 vs 居民），期限结构（短端 vs 长端）

**信用扩张的核心矛盾**
央行释放流动性 ≠ 信用确实进入实体经济。经典场景：
央行降息降准 → 银行间流动性充裕（DR007 很低）→ 但企业和居民不愿借钱（资产负债表还没修复）→
资金在金融体系空转 → 国债收益率下行，但实体经济未见起色

**货币政策传导机制**
1. 利率渠道：政策利率 → 银行间利率 → 存贷款利率 → 企业/居民融资成本 → 投资/消费
2. 信贷渠道：准备金率 → 银行可贷资金 → 信贷可得性 → 经济活动
3. 资产价格渠道：宽松 → 股票/房产上涨 → 财富效应 → 消费增加
4. 汇率渠道：利率差 → 资本流动 → 汇率变动 → 进出口竞争力

**中国货币政策工具箱的独特之处**
- 数量型工具和价格型工具并用（发达经济体主要用价格型）
- 结构性货币政策（PSL 抵押补充贷款、再贷款再贴现、定向降准）
- 窗口指导的隐性存在（信贷额度管控、房地产信贷限制）
- 利率双轨制：政策利率 ↔ 市场利率 不完全同步

### 2.3 财政分析框架

**关注三个赤字**
- 一般公共预算赤字
- 政府性基金赤字（土地出让收入是关键变量）
- 广义财政赤字（包括地方融资平台、专项债）

**财政乘数**
1 块钱财政支出能带动多少 GDP？取决于：
- 支出投向（基建 > 消费补贴 > 减税）
- 经济周期位置（衰退期乘数 > 扩张期）
- 居民和企业的边际消费/投资倾向

**中国财政的特殊性**
- 显性赤字不大，但隐性债务（地方融资平台、城投）体量巨大
- 土地财政贡献了地方收入的大头，房地产下行直接压缩财政空间
- 专项债是近年最重要的政策工具，但资金使用效率存疑

### 2.4 全球经济联动框架

**核心传导渠道**
- **贸易渠道**：美国衰退 → 中国出口下滑 → 制造业承压
- **金融渠道**：美联储加息 → 美元走强 → 新兴市场资本外流 → 货币贬值
- **政策渠道**：主要央行同步收紧 → 全球流动性收缩 → 风险资产普跌
- **信心渠道**：全球风险事件 → VIX 飙升 → 资金涌入避险资产

## 3. 资产配置框架

### 3.1 战略资产配置 vs 战术资产配置

- **战略配置**：长期基准权重，基于你的目标、时间维度和风险承受力。5-10 年不变。
- **战术配置**：短期偏离战略权重，基于当前市场判断。6-18 个月的窗口。

好的配置是：战略权重像压舱石，战术偏离像帆——前者保证不翻船，后者争取超额收益。

### 3.2 经典配置模型

**60/40 股债组合**
最简单也最经典的基准。60% 股票 + 40% 债券。逻辑：股票增长 + 债券防御。
问题：在股债同涨同跌的环境中失效（2022 年股债双杀）。

**全天候组合（All-Weather）- 达利欧**
不预测宏观情景，而是对四种情景做风险平价配置。在不同通胀/增长组合下都有资产能表现好。
核心思想：风险来源的分散比资产数量的分散更重要。

**耶鲁模型（Endowment Model）- 斯文森**
大幅超配另类资产（PE/VC/对冲基金/实物资产），利用永续时间维度承担非流动性换取溢价。

**永久组合（Permanent Portfolio）- 哈里·布朗**
25% 股票 + 25% 长期国债 + 25% 现金/短债 + 25% 黄金。
四种经济情景各有一个 "受益方"。简单但出奇稳健。

**核心-卫星策略**
核心仓位（70-80%）放在低成本指数基金/ETF 上，卫星仓位（20-30%）做主动选择和战术策略。
平衡了 "不要太差" 和 "可能更好"。

### 3.3 中国投资者的配置考量

**独特资产**
- 房产（大部分中国家庭的最大资产，但流动性差、集中度高）
- 银行理财/信托（刚兑打破中，信用风险重定价）
- 保险产品（预定利率下调趋势）

**汇率维度**
海外资产配置 = 资产本身回报 + 汇率变动。人民币贬值趋势下，
海外配置的汇率收益可能超过资产本身收益。

**跨境配置工具**
- QDII 基金（额度限制，有时暂停申购）
- 港股通（最便捷的人民币出海渠道）
- 互认基金（中港基金互认，品类有限）

## 4. 风险管理体系

### 4.1 风险的维度

| 风险类型 | 定义 | 管理方式 |
|---------|------|---------|
| 市场风险 | 价格波动 | 分散+对冲 |
| 信用风险 | 对手方违约 | 评级+限额 |
| 流动性风险 | 无法及时以合理价格买卖 | 仓位控制+压力测试 |
| 集中度风险 | 单一资产/行业权重过大 | 硬性上限 |
| 行为风险 | 自己情绪导致的错误决策 | 规则+纪律 |
| 通货膨胀风险 | 购买力被侵蚀 | 实物资产+通胀挂钩债券 |
| 汇率风险 | 跨境投资的汇率波动 | 对冲或接受 |

### 4.2 仓位管理的核心原则

**不爆仓是第一纪律。** 无论多大的机会，杠杆要控制在即使最坏情况发生你也能扛过去的范围。

**不要让自己陷入被迫卖出的境地。** 现金储备不是为了抓机会，而是为了不被机会抓。当所有人都被迫卖出时，手里有弹药就是最大的权力。

**波动不是风险，永久性亏损才是。** 区分"股价跌了"和"价值毁灭了"。好公司短期跌 30% 是机会，差公司跌 30% 可能是价值回归。

### 4.3 回撤控制

如果最大回撤让你睡不好觉，你的仓位太大了。
回撤控制的黄金法则：持仓规模 = 你能承受的回撤金额 / 资产可能的跌幅。

## 5. 行为金融学

### 5.1 核心认知偏差

**损失厌恶（Loss Aversion）**
失去 100 元的痛苦 ≈ 赚到 200-250 元的快乐。这解释了为什么投资者过早止盈（锁定利润的快乐）
而迟迟不止损（不愿意面对亏损变为现实）。

**处置效应**
投资者倾向于卖出盈利的股票、持有亏损的股票。行为金融实验反复验证这一点。
理性做法恰恰相反：留下好公司，卖出坏公司，不管成本是多少。

**锚定效应**
被某个数字"锚住"而无法调整。最常见的：以买入价格作为是否卖出的锚。
但买入价格和市场对这只股票未来的判断没有任何关系，它只是你已经发生的成本。

**确认偏误**
倾向于寻找支持自己观点的信息，无视反面证据。投资中最昂贵的一个偏误。
买了就只看利好，卖了就只看利空。

**近因效应**
给最近发生的事过高权重。2020 年觉得股票永远不会跌，2022 年觉得股票永远不会涨。
每一轮牛熊都在重演近因效应的剧本。

**过度自信**
大多数人认为自己比平均水平更聪明。90% 的司机认为自己的驾驶水平高于中位数。
在投资中表现为：过度交易、集中度过高、忽视风险。

**羊群效应**
别人买我就买，别人卖我就卖。短期来看这种"跟随"能带来安全感，
但超额收益永远不可能来自做和别人一样的事。

**可得性偏差**
容易想到的、最近被媒体密集报道的事件被赋予过高权重。坠机后被问"交通事故死亡率上升了吗？"
大部分人会说是，尽管数据并未变化。

**叙事谬误**
人类天然喜欢有起因-发展-结局的故事。股市每天涨跌都有人写出"原因"，
"因为美联储某官员说了XX所以股市跌了"。这些叙事大部分是事后归因的幻觉。

### 5.2 如何对抗行为偏差

- **写下投资逻辑，而不仅仅是决策**。将来复盘时能看到当时的真实想法，而非记忆重构后的版本。
- **用规则代替判断**。比如"任一持仓浮亏超过 15% 必须重新评估，超过 20% 无条件减半"。
- **不要在盘中做重大决策**。盘中情绪放大器效应显著，盘后冷静比盘中激情重要十倍。
- **降低看盘频率**。T+0 的日内波动绝大多数是噪音，高频看盘只会放大焦虑和冲动。

## 6. 行业分析框架

### 6.1 波特五力模型

1. **行业内现有竞争者的竞争强度**：集中度高还是分散？价格战频繁吗？
2. **新进入者的威胁**：进入壁垒高吗？需要多少资本？监管许可？
3. **替代品的威胁**：有别的产品/服务能满足同样需求吗？
4. **供应商的议价能力**：上游集中吗？能不能换供应商？
5. **买方的议价能力**：客户集中吗？转换成本低吗？

五力决定了行业的平均利润率。五力越弱（对在位者越友好），行业的长期回报越高。

### 6.2 行业生命周期

```
导入期 → 成长期 → 成熟期 → 衰退期
  ↓         ↓        ↓        ↓
高增长    增速最快  增速放缓  负增长
不盈利    开始盈利  盈利稳定  盈利萎缩
高风险    高估值    估值收缩  折价
```

核心判断：公司在哪个阶段？市场给的是哪个阶段的估值？
如果市场给的是成长期估值但行业已经进入成熟期，那是卖出的信号。

### 6.3 重要行业的分析要点（速查）

**消费行业**
护城河看品牌力、渠道力、产品力。关键指标：同店销售增速、毛利率趋势、存货周转。
A 股的消费品逻辑：渠道下沉（拼多多证明了三四线的力量）、消费升级与降级并存。

**科技行业**
核心看技术路线选择、研发效率、生态壁垒。高研发投入 ≠ 高研发效率。
A 股科技：半导体国产替代是长期趋势，但估值已经把未来若干年的预期打进去了。

**金融行业**
银行看净息差（NIM）、不良率、拨备覆盖率。保险看新业务价值（NBV）、内含价值（EV）。
券商看市场成交量和 IPO 节奏。银行股在 A 股的独特逻辑：高股息 + 国有资产重估。

**医药行业**
创新药看管线（pipeline）、研发成功率、专利悬崖。CXO 看在手订单和产能利用率。
A 股医药：集采是最大的行业变量，压制仿制药利润但推动创新转型。

**新能源行业**
光伏看技术迭代和产能过剩周期。锂电看上游锂价和下游需求增速。
核心矛盾：长期趋势确定，但短期产能过剩、价格战、利润压缩是常态。

**房地产行业**
早已从增量逻辑转为存量逻辑。关键看融资渠道是否通畅、土储布局、现金流。
中国房地产的特殊性：政策周期是第一驱动力，不是市场周期。

## 7. 财务分析核心指标

### 7.1 盈利能力

| 指标 | 公式 | 关注点 |
|------|------|-------|
| 毛利率 | (收入-成本)/收入 | 趋势比绝对值重要；持续下降是危险信号 |
| 净利率 | 净利润/收入 | 排除非经常性损益后看；低于同行要深挖 |
| ROE（净资产收益率） | 净利润/净资产 | 杜邦分解：净利率×周转率×杠杆倍数 |
| ROIC（投入资本回报率） | NOPAT/投入资本 | 比 ROE 更纯粹，排除杠杆效应 |

**ROE 杜邦分解**
```
ROE = 净利率 × 资产周转率 × 权益乘数
     = 赚得多 × 转得快 × 借得狠
```
三种高 ROE 模式各有风险：
- 高净利率驱动（茅台）：看品牌溢价能否持续
- 高周转驱动（沃尔玛、Costco）：看效率壁垒
- 高杠杆驱动（银行、地产）：看杠杆是否过大

### 7.2 成长性

- **收入增速**：拆分量×价，看量增还是价增
- **利润增速**：是否持续快于收入（经营杠杆的体现）
- **现金流增速**：最真实的增长，现金流不能造假（但可以"调整"）

### 7.3 偿债能力

| 指标 | 公式 | 使用场景 |
|------|------|---------|
| 流动比率 | 流动资产/流动负债 | >2 为健康，<1 为危险 |
| 速动比率 | (流动资产-存货)/流动负债 | 去除了变现慢的存货 |
| 资产负债率 | 总负债/总资产 | 重资产行业偏高是正常的 |
| 利息覆盖倍数 | EBIT/利息费用 | <1.5 意味着利润可能不够付利息 |

**A 股特别关注**：大股东质押比例。高比例质押 + 股价下跌 = 强平风险 + 控制权变更风险。

### 7.4 现金流

| 指标 | 含义 |
|------|------|
| 经营现金流 | 真金白银从生意里赚到的钱 |
| 自由现金流 | 经营现金流 - 资本支出 = 真正能给股东的钱 |
| 净现比 | 经营现金流/净利润，<1 意味着利润可能有水分 |

**核心规则**：利润可以操纵（会计手段），现金流难以长期伪造。连续多年利润增长但经营现金流不匹配的公司，迟早出问题。

### 7.5 其他核心指标速查

- **存货周转天数**：存货从进来到出去的平均时间。上升 = 滞销风险。
- **应收账款周转天数**：客户欠你钱的平均时间。上升 = 回款恶化或虚增收入。
- **商誉/净资产比**：商誉占比过高，减值风险大，尤其A股2015年前后大量并购留下的商誉。
- **研发资本化率**：研发支出有多少计入了无形资产而非费用。高资本化率 = 利润被美化。
