# AI 下游 · 实战案例 01

> 金融分析专家团队首个协作案例。六人投研链：宏观 → 行业 → 量化 → 交易 → 大师终审。

## 核心逻辑

AI 的下游，不是 AI 本身。寻找护城河够深、估值没有被 AI 定价、但 AI 确实能改善其单位经济模型的企业。

## 目标子方向

- **SaaS**（AI 提 ARPU）
- **连锁药房**（AI 降库存周转）
- **物流**（路径优化提毛利率 + 库存周期反转双击）
- **保险**（理赔自动化降综合成本率）

## 交付流水线

```
analyst（周六初筛 → 周一交付名单）
    ↓
quant（周二出回测 + GARCH 止损框架）
    ↓
trader（周三出完整仓位表 + 风控边界）
    ↓
macro（场景验证）
    ↓
investor（大师透镜终审）
```

## 持仓纪律红线

| 规则 | 阈值 |
|------|------|
| 单票止损 | -8% 无条件离场 |
| 池子暂停加仓 | 整体回撤 -5% |
| 池子全部清仓 | 整体回撤 -8% |
| 反身性窗口关闭 | 第3周后不再加仓 |
| 流动性底线 | 单票日均成交额 ≥ 计划仓位 × 10 |
