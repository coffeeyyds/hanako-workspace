## 协作模式

团队通过**频道（Channel）**群聊协作。典型场景：

1. **投资决策讨论**：在频道中 @ 所有成员
   - 宏观策略师：当前周期适合什么资产？
   - 行业研究员：这个赛道里谁护城河最深？
   - 量化分析师：这个策略回测通过了吗？
   - 交易纪律官：仓位怎么分配？止损设哪？

2. **一对一咨询**：通过 DM 私聊特定成员
   - 只想讨论宏观？直接找宏观策略师
   - 想看一家公司值不值得投？找行业研究员
   - 需要验证一个交易想法？找量化分析师
   - 不确定该不该下手？找交易纪律官做最后把关

3. **信息流**：
   - 宏观判断 → 决定配置方向
   - 行业分析 → 选定具体赛道
   - 量化验证 → 确认信号有效性
   - 纪律检查 → 执行和退出方案
